# 介绍

**Sumi · 墨** 是一个用于 [MoonBit](https://www.moonbitlang.com) Web 应用的 UI 组件库，基于 rabbita TEA 框架构建。组件就是返回 HTML 的普通函数——没有 CSS 流水线，没有构建配置。

## 内容概览

- **30+ 组件**，覆盖操作、表单、浮层、反馈与展示
- **深浅双调色板**：同一套 token 作用于 CSS 自定义属性；`System` 模式实时跟随系统外观
- **内置浮层动效**：菜单、文字提示、对话框与轻提示在出现*和*消失时均有动画，来自同一份常驻样式表
- **键盘导航**：菜单中的漫游焦点与方向键/Home/End、Esc 关闭、右键菜单指针追踪，全部由 `theme()` 注入的轻量事件层处理

## 设计原则

**受控组件。** 所有状态由调用方持有并传入。菜单不会自己打开——你用 `open` 变量渲染它，并在 `on_open_change` 中更新该变量。这与 TEA 更新循环直接对应——永远不存在隐藏的组件状态。

**token 而非常量。** 每个颜色、圆角与阴影都通过 `var(--sumi-*)` 自定义属性解析，因此一个 `theme()` 包裹层即可为整棵树换肤——你也可以用普通内联样式覆盖任意 token。

**深色兜底。** 每个 token 在组件内都带有深色模式的回退值，因此即使没有 `theme()` 包裹层，组件也能正常渲染（呈深色）。推荐但非强制使用包裹层。

## 包结构

模块将组件放在类目包中，依赖单向流动——`internal ← primitives ← overlays ← forms`，`feedback` 与 `layout` 在侧——并通过根门面统一再导出，调用方始终只需一个扁平的 `@sumi.*` 导入。
